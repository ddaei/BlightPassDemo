# BlightPassDemo

블라이트 워 7일 패스 「집행관 정식 임명」의 보상표를 CSV로 읽어 Unity 화면에 표시하는 데모입니다.
게임 라이브 기획 포트폴리오의 "기획 수치 → 데이터 테이블 → 게임 화면" 흐름을 직접 확인하려고 만들었습니다.

## 무엇을 하나

- 엑셀로 설계한 보상표(35레벨, 일반·프리미엄 73줄)를 CSV로 내보내 Unity가 읽습니다.
- 수량을 바꿀 때 코드는 고치지 않고, CSV만 바꾸면 화면에 반영됩니다.
- Inspector에서 CSV 이름, 제목, 글자 크기, Premium Only(프리미엄 보상만 보기)를 바꿀 수 있습니다.

## 실행 방법

1. Unity 6(6000.6.6f1)으로 이 프로젝트를 엽니다.
2. `Assets/Scenes/SampleScene`을 열고 Play를 누릅니다.
3. Hierarchy에서 `PassRewardLoader`를 선택하고 Inspector의 **Premium Only**를 켜면 프리미엄 보상만 표시됩니다.

## 주요 파일

| 파일 | 내용 |
|---|---|
| `Assets/Resources/pass_rewards.csv` | 보상표 (reward_id, 레벨, 누적 EXP, 트랙, 아이템, 수량 등) |
| `Assets/Scripts/PassRewardLoader.cs` | CSV를 읽어 레벨별 보상을 화면에 표시하는 스크립트 |
| `Assets/Prefabs/PassBoard.prefab` | 보상판 프리팹 (프리팹 원본 수정이 씬에 반영되는지 테스트용) |

## 기획 수치 변경 이력

보상 수치를 바꿀 때마다 커밋으로 남겼습니다. History에서 무엇을, 왜 바꿨는지 볼 수 있습니다.

- `3·8레벨 보상을 황령의 원란으로 변경`
- `예지의 구슬 보상 50-> 300 상향`
- `프리미엄 성장 배율 증가(5->10)`
- `구슬 프리미엄 보상 수량 변경(3000->2000)`: 11만 원 구슬 패키지 판매를 잠식하지 않도록, 지옥 패스 소집석 배율(약 6.7배)로 낮춤

## 참고

기획 의도는 포트폴리오 9\~16장, 보상 밸런스 계산(엑셀 수식)은 17\~21장, 지옥 패스와의 비교는 15장과 20장, 이 저장소의 Unity·Git 구현은 22\~25장에 정리했습니다.
